# Hero and Footer Refresh

## Goal
Refine Remember’s first and final impressions with a calmer aura-led opening, stronger status banner, a scroll-reactive vertical beam, and a more substantial footer.

## Build
- Replace the hero’s scattered memory-node network with a focused emerald-and-gold aura, concentric memory rings, and restrained flowing light.
- Redesign the top badge as a sharper live infrastructure status banner with clearer hierarchy.
- Add a slim futuristic beam that progresses vertically as the page scrolls and subtly highlights nearby section markers.
- Recompose the hero spacing and supporting system details so the product reads more immediately as an AI memory gateway.
- Replace the minimal footer with a structured closing area containing brand positioning, section links, developer resources, and open-source status.
- Keep the final call-to-action distinct from the new hero treatment and preserve the existing mobile navigation and content sections.

## Technical Details
- Use lightweight CSS gradients, masks, SVG rings, and a passive scroll listener; no new dependencies or heavy canvas effects.
- Extend existing semantic color tokens and respect reduced-motion settings.
- Verify desktop and mobile layouts for legibility, overflow, scroll progress, and runtime errors.
