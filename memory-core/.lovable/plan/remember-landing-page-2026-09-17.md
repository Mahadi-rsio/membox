# Remember Landing Page

## Goal
Build a premium, responsive one-page website that explains Remember through its memory network, processing pipeline, context compression, and developer workflow.

## Build
- Replace the blank homepage with a complete dark infrastructure landing page and floating glass navigation.
- Create lightweight SVG/CSS network visuals with memory nodes, traveling signals, particles, data packets, and cursor-responsive depth.
- Add sections for the system pipeline, context compression, connected memories, capabilities, architecture, philosophy, terminal workflow, live retrieval demo, MCP, open source, and final call to action.
- Use restrained emerald, charcoal, white, and metallic gold visual tokens with technical typography, subtle grain, luminous borders, and purposeful glass surfaces.
- Make all calls to action functional as page links or project links, with accessible focus states and mobile navigation.
- Reduce visual density and motion on smaller screens and honor reduced-motion preferences.

## Technical Details
- Keep the experience dependency-light with React, SVG, CSS keyframes, pointer events, and IntersectionObserver-style CSS reveals.
- Define all color, typography, glow, and surface values as semantic tokens in the global design system.
- Add route-specific page metadata and font loading.
- Verify the finished page at desktop and mobile sizes, including overflow, legibility, and runtime errors.
